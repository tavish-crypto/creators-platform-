# Creator Platform

A MERN Stack application where users can create, edit and delete projects.

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- JWT Authentication

## Installation

### Backend

```bash
cd server
npm install
npm run server
```

### Frontend

```bash
cd client
npm install
npm run dev
```

## Environment Variables

Server

```
PORT=
MONGO_URI=
JWT_SECRET=
```

Client

```
VITE_API_URL=
```
